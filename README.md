# 🍬 Candy Crush Clone (C++ & SFML)

A classic Match-3 puzzle game inspired by **Candy Crush**, built from scratch in **C++** using the **SFML** graphics library.

## ✨ Planned Features
- [ ] Interactive 2D game board with colorful candy tiles
- [ ] Mouse-click tile swapping and match-3 detection logic
- [ ] Cascading board refills, combos, and score tracking
- [ ] Custom sprites, smooth animations, and sound effects

## 🛠️ Built With
- **Language:** C++
- **Graphics Library:** SFML (Simple and Fast Multimedia Library)
- **IDE:** Visual Studio

## 🚀 Project Status
Currently in active development! Game mechanics and visual assets are being built step-by-step.
